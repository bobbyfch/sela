# Explore inside your personal reader

Read a temporary preview or use the download icon to save a copy in your private shelf. Catalogs load on Explore, rather than in the SDK main entry. Explore stays in one responsive bookseller-style shelf: covers only, 2–5 columns by screen width. Tap a cover to see its edition details and reading actions.

Explore opens as a cover-first bookseller. Its categories separate open/public editions, Google Books free eBooks, and paid/preview listings, and include ten genre shelves, top reads, hidden gems, new releases, “For you”, and “Surprise me”. Search is available across the selected source. The top-reads shelf reflects Open Library reader activity; the hidden-gem shelf uses a small-rating-count filter. Neither is a sales ranking. Open Library and Google Books cover URLs use the largest provider size exposed for that edition; a cover download action appears only when the source provides an allowed image URL. Cover resolution and permission remain provider-dependent.

Google Books cards retain visible “Powered by Google” attribution and link to the relevant Google book page. A “Google Preview” action is shown only when the volume has a preview URL. A purchase action uses Google’s validated buy link where available; otherwise it opens a Google Shopping search for the title and author. Google availability and price depend on the selected country. Open Library’s `L` cover variant is requested for direct cover download where available; its documentation asks applications to avoid bulk cover crawling.

Home’s “On this day” widget requests the localized Wikimedia history feed, then falls back to English if the selected Wikipedia has no suitable entries. Wikimedia is gradually replacing the API Portal route during July 2026–June 2027; its migration table lists the project-local `/api/rest_v1/feed/onthisday/...` route that Sela already uses. Wikifeeds still marks this endpoint experimental, so the English fallback remains useful and the source status should be monitored ([migration schedule](https://wikitech.wikimedia.org/wiki/API_Portal/Deprecation), [Wikifeeds endpoint status](https://www.mediawiki.org/wiki/Wikifeeds)). Topic news uses GDELT’s multilingual article-list API with the user’s selected topics and app language. Search terms are sent unquoted because GDELT rejects short exact phrases, including Indonesian terms such as “alam” and “seni”; GDELT can also return HTTP 429 when its public API is busy. Indonesian topic feeds first use ANTARA RSS (Humaniora for books, Tekno for science/technology, Warta Bumi for nature, Lifestyle for art, and Hiburan for culture), then GDELT, ANTARA latest-news RSS, and finally Google News RSS. English and Japanese fall back from GDELT to topic-search Google News RSS; the Indonesian Google News feed is unfiltered at the provider and is matched against selected topic terms locally. RSS2JSON is used only as a browser CORS bridge for Google News RSS, not as the publisher or source of the headlines. The last successful topic results are retained in the browser when a fresh request fails. ANTARA publisher-supplied `enclosure`/`media:content`/`media:thumbnail` images and GDELT social images are used when returned; Google News RSS often has no per-story image, so Sela keeps a consistent placeholder rather than inventing a cover. The publisher and original article link stay visible when available. Topic-to-section matching is editorial rather than a guarantee that every headline matches every selected subtopic. The quote shelf uses Wikiquote search and preserves the source-page link; Wikipedia portraits are displayed only when a matching public thumbnail is returned. These feeds are optional network content and can be unavailable without affecting the local bookshelf.

## Faith and scripture readings

The faith preference is optional, stored only in this browser’s Sela personal settings, and defaults to “No preference”. Sela never infers a user’s religion. The selector offers the six religious categories officially recognized in Indonesia: Islam, Protestant Christianity, Catholic Christianity, Hinduism, Buddhism and Confucianism. When chosen, Home loads a sourced reading only when a compatible public edition is available; every passage identifies its actual text language, edition and source. The “Browse the Quran” action loads a selected surah on demand and opens it as HTML in Sela Viewer. QuranEnc offers Indonesian (`indonesian_affairs`, identified by its API as the Kementerian Agama translation), English (Saheeh International) and Japanese (Saeed Sato) translations. Its API terms require attribution and version retention, prohibit changing the published translation, and ask clients to follow new issued versions. The Islam Home shelf also has Quran chapters and daily adhkar collections; the latter use Buruja’s published Arabic, transliteration and English meanings with the source references retained. The English meaning is explicitly identified and is not silently machine-translated for Indonesian or Japanese UI users.

The Quran reader pairs Arabic text with the selected, attributed QuranEnc translation. Its per-surah study link opens Qur’an Kemenag, which publishes the surah’s Arabic, Indonesian Latin transliteration, translation and tafsir; the published Latin method follows the joint Ministry of Religious Affairs and Ministry of Education transliteration standard. The reader also links to LPMQ publications on the meanings of all surah names, Makki/Madani revelation periods, and asbabun nuzul. These are source references, not Sela-written tafsir or a complete per-surah chronology. The official color-coded tajwid and Latin reading guide currently linked here covers Juz Amma only; Sela does not apply unsourced tajwid labels to other chapters. Qur’an Kemenag’s developer API offers official Mushaf Standard Indonesia text, translations and tafsir, but its portal requires registration and a formal access request, so no API token is embedded in this static public client. The Home story shelf is a selection of Qur’anic passages with explicit surah/verse references; selecting a card opens that cited passage in the reader rather than adding unsourced narrative details. LPMQ’s “Kisah Para Nabi Pra-Ibrahim” publication is clearly labeled as limited to prophets before Ibrahim.

The other adapters are explicit about limits. Protestant readings use the public-domain World English Bible in English. Catholic readings link to the official Lembaga Alkitab Indonesia API but stay outside the in-app reader until its access credentials and edition terms are available. Buddhist readings use Bhikkhu Sujato’s English passages from SuttaCentral. Hindu readings show Sanskrit, or the API’s English rendering when English is selected. Confucian readings link to the Analects in the Chinese Text Project; its API requires a registered key/IP, so Sela does not pretend to load it directly. Source language stays visible when it differs from the selected UI locale; Sela does not machine-translate sacred texts or present paraphrases as scripture. eBible.org lists Indonesian AYT, but its stated CC BY-ND-NC terms prohibit commercial use, so this reusable adapter does not silently bundle it. The official Qur’an Kemenag API is another future adapter option, but currently requires a registered request; QuranEnc’s Kemenag-labelled edition is used for the no-key public client. Provider availability is not a religious authority, and unsupported or unavailable editions retain a direct source link instead of fabricated fallback text.

`src/scriptures.ts` exports `getDailyScripture`, `getQuranChapter`, `getQuranTranslations`, `getIslamicReadingCollection`, `openIslamicCollection`, `createScriptureDocument`, and the provider registry from the `@bobbyfch/sela/scriptures` package path. The adapters are framework-independent and open safe HTML reading documents through Sela Viewer with `format: 'html'`. The Bhagavad Gita API currently states that its hosted service is free for non-monetized applications; replace or disable that adapter before monetizing a host. For any faith-specific deployment, verify each provider’s current translation license and edition metadata before adding offline bundles or changing the text.

There are **28 source choices**, not 28 independent book collections. Multilingual Wikisource choices share a provider, and Open Library’s browse, search, top-reads and hidden-gem views use the same catalog. Results deduplicate IDs within the active source; SHA-256 prevents saving identical files twice. Different editions are not silently merged.

**Read** fetches a bounded file and opens an ephemeral preview. Closing cleans up viewer resources; it does not add the book to IndexedDB. **Download / Save offline** validates and stores it in the private shelf. Metadata-only cards offer **View edition**. Explore shows locally generated cover artwork immediately, then loads provider art near the viewport from HTTPS allowlisted Gutenberg and Open Library endpoints. Imported books remain local: Sela does not send their ISBNs to a cover service. Text transcriptions lack EPUB/PDF publisher layout fidelity.

## Personal catalogs

Save named HTTPS OPDS profiles for compatible Calibre-Web/Kavita/Komga servers. Optional username/password stay in the current sheet/session and are not persisted. Authorization is scoped to the origin where credentials were supplied; external acquisition/navigation links do not inherit it. Servers must permit the Sela origin and required auth headers through CORS. HTTP servers cannot be fetched from an HTTPS app. Importing a file is still available when remote access fails.

Catalog profiles are local preferences. OPDS discovery does not itself sync progress; optional manual WebDAV backup is a separate connection. Nothing bypasses lending restrictions, DRM, provider quotas or membership.

## Live availability

Provider availability varies with network access, CORS and each catalog's current status. Failed sources keep a retry, source link and Selected classics fallback. A saved edition works offline only while its original bytes remain stored; local validation reports are kept outside the public release.
