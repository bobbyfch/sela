# Built-in classic collection

Explore → Find open books offers eight complete English editions: Pride and Prejudice, Alice’s Adventures in Wonderland, Frankenstein, The Adventures of Sherlock Holmes, Little Women, Metamorphosis, Dracula and A Tale of Two Cities.

Search titles, authors and genres locally. Every result has an original typographic cover, Read and Save offline. Read downloads the selected text, saves it in IndexedDB and opens the Sela reader. Failed downloads stay in the app and can be retried. No results redirect to another reader. This curated collection does not claim to search the entire internet or provide copyrighted commercial novels.

Texts are Project Gutenberg editions preserved by [GITenberg](https://gitenberg.org/). Download URLs are pinned to repository commits in `library/public-books.json`. Credits, translation notices and Project Gutenberg terms remain in the original text. These editions are public domain in the United States; local copyright rules can differ. The collection metadata is small and cached with the app; book content is fetched only after an explicit action. Saved books remain local.

Covers are generated by Sela from titles and authors, and are not the original publishers’ cover art. Plain-text editions have fewer formatting features than EPUB editions. You can import your own EPUB/PDF/comic files for richer layouts.
