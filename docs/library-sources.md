# Discover books inside Sela

Open Explore to search, read or save an offline copy. No account or OAuth setup is required. Catalog modules load when Explore is opened, not as part of the CDN Viewer.

| Source | Search and acquisition | Scope |
| --- | --- | --- |
| GITenberg | External title/author search with pagination; original text downloaded from the repository into Sela | Project Gutenberg editions; public-domain status is US-specific. Source terms remain in each book. GitHub public API quotas apply; repeated queries are cached for 15 minutes. |
| Wikisumber Indonesia | Indonesian novel category or full-text title search; source page and up to 100 subpages assembled into a safe reflow document | Contributor transcription may be incomplete. Source/revision link and CC BY-SA contribution notice are preserved; original work rights remain source-specific. |
| Selected classics | Eight bundled catalog entries, local search, original pinned text files fetched only on Read/Save | Small fallback collection, including Austen, Carroll, Shelley and Doyle; not a replacement for external search. |
| Your OPDS catalog | OPDS 1 Atom or OPDS 2 JSON navigation, pagination and direct open acquisitions | HTTPS, browser CORS access, no login. Buy/borrow/indirect DRM entries are excluded. Search filters the currently fetched feed; it is not an arbitrary server-wide OPDS search engine. |

Read downloads, validates and saves the selected file into the private shelf before opening the reader. Failed requests show a retryable message without inventing an imported book. No acquisition redirects to another reader. Discovery metadata and file availability can change; Sela cannot guarantee an external source's uptime or a complete copy of every book.

Covers are generated by Sela from titles and authors, not presented as original publisher cover art. Plain text and transcriptions have less formatting fidelity than publisher EPUB/PDF editions. Save a copy for offline reading; do not clear site data without a backup.

## Personal Calibre catalogs

Choose **OPDS · Your catalog**, enter an open HTTPS OPDS URL, then Search. Navigation sections open inside Sela. The server must allow the Sela origin through CORS. A local HTTP-only Calibre server cannot be fetched from an HTTPS page because of browser mixed-content rules. This integration does not bypass server authentication, lending restrictions or DRM; local-file import remains available.

Provider references: [GITenberg](https://gitenberg.org/), [GitHub public search limits](https://docs.github.com/en/rest/search/search), [Wikisumber Indonesia](https://id.wikisource.org/), [OPDS 1.2](https://specs.opds.io/opds-1.2), [OPDS 2.0](https://specs.opds.io/opds-2.0).
