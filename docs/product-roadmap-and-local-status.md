# Current product scope — Sela Reader 1.3

Reader is an installable web app for desktop, tablet and phone. Viewer is the reusable CDN/ESM reader for websites. Browser-extension packaging, separate Home editions and OS installation gates have been removed.

Implemented: responsive Home/Shelf/Explore/Settings, library sorting/filtering/collections/favorites, full ZIP backup and merge restore, compact app reading controls, runtime modes/fit/typography, TTS, embedded outline/search/notes, manual cloud backup, original public hero and sample/upload grid.

Future work: finished novels and covers, OPDS catalog discovery, EPUB CFI and range annotation, optional authenticated synchronization and a measured accessibility audit. No unfinished novels are represented as available samples.
