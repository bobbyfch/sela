Install on your device
  1. 1Open Sela Books, then tap Install Sela when the app offers it.
  2. 2Chrome, Edge, Opera and Samsung Internet show their own install prompt when this browser supports it.
  3. 3On iPhone or iPad, open the Share menu in Safari and choose Add to Home Screen. On macOS Safari, choose File → Add to Dock.
  4. 4Firefox offers a home-screen shortcut on Android. On desktop, use its Web Apps option where available or bookmark Sela.

Sela checks whether this browser has already installed the app and hides the install action when it confirms. Options vary by browser and operating system.

More reading settings

Ctrl + wheel or trackpad pinch zooms; normal scrolling stays natural. Press ? inside the reader for shortcuts. EPUB uses chapter-based text reading.

Your website setup

For your own file, upload it to a URL your website can access and replace the sample URL in this snippet.

PDF, EPUB, comics and text have optional reading tools: contents, search, narration and notes. FB2 is text-only; DjVu uses an external GPL-2.0 decoder.

Works with plain HTML, React, Vue, Laravel, CodeIgniter and other stacks. Your site needs a document URL that visitors can access.

Installation and integration guide ↗

A softer reading space

Twelve page presets, a document brightness slider and dimmed controls. Separate tabs for contents, search, appearance, narration, notes and selectable text.

A graceful way back

Modern browsers get the full viewer. Older browsers get the original PDF via the compatibility entry. Windows, macOS, Linux, Android and iOS follow browser capabilities.

Open source, clear origins

MIT reader, PDFlipbook page engine and lazy Apache-2.0 PDF.js. No framework runtime. Keyboard controls, saved progress and bookmarks included.

Reader diagnostics
Open a document to inspect its lifecycle. Document text, URLs, headers and error messages are excluded.
